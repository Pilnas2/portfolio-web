# 🚀 Moderní Portfolio Webovka

Moderní osobní portfolio webová stránka postavená na React, TypeScript a Tailwind CSS, optimalizovaná pro GitHub Pages.

## ✨ Funkce

- 📱 **Plně responzivní design** - vypadá skvěle na všech zařízeních
- 🎨 **Moderní UI/UX** - čistý a profesionální vzhled
- ⚡ **Rychlé načítání** - optimalizováno pro výkon
- 🌟 **Smooth animace** - elegantní přechody a efekty
- 📧 **Kontaktní formulář** - funkční komunikace
- 🎯 **SEO optimalizované** - připraveno pro vyhledávače

## 🛠️ Technologie

- **Frontend**: React 19 + TypeScript
- **Styling**: Tailwind CSS s custom designem
- **Ikony**: Lucide React
- **Build tool**: Vite
- **Deployment**: GitHub Pages
- **Animace**: Custom CSS animace

## 🚀 Rychlý start

### Instalace
1. Klonování repozitáře a instalace závislostí:
   ```bash
   git clone https://github.com/your-username/portfolio.git
   cd portfolio
   npm install
   ```

2. Spuštění dev serveru:
   ```bash
   npm run dev
   ```

3. Otevření v prohlížeči: `http://localhost:5173`

## 🌐 Deployment na GitHub Pages

1. Aktualizujte URL v package.json:
   ```json
   "homepage": "https://your-username.github.io/repository-name"
   ```

2. Deploy:
   ```bash
   npm run deploy
   ```

## 📝 Personalizace

Upravte tyto soubory s vašimi údaji:
- `src/components/Hero.tsx` - jméno, tituly, popis
- `src/components/About.tsx` - osobní story, statistiky
- `src/components/Projects.tsx` - vaše projekty
- `src/components/Contact.tsx` - kontaktní údaje
